# The Four Primitives and Weapons

**鎧を貫け。日頃の鬱憤を敵にぶつけろ。**
_Penetrate armor. Take out your daily grudges on your enemies._

***

> このModは日本人学生のチームによって作られています。英語の説明が不自然な箇所があるかもしれません。ご了承ください。
> This mod is made by a team of Japanese students. Apologies for any awkward English phrasing!

***

## 📦 概要 / Overview

武器・防具・鞘システムをMinecraftに追加するModです。
<span style="color:#c2e0f4">氷</span>・<span style="color:#f1c40f">電気</span>・<span style="color:#ff00c8">侵食</span>・<span style="color:#fbeeb8">聖</span>・<span style="color:#5d3a8c">闇</span>・<span style="color:#ff6347">火</span>・<span style="color:#88d99c">風</span>・<span style="color:#b388ff">雷</span>・<span style="color:#4dabf7">水</span>・<span style="color:#95a85a">瘴気</span> の **10種類の属性** を武器に宿らせ、敵の防御を貫いて日頃の鬱憤を晴らしましょう！

Adds elemental weapons, armor, and a sheath system to Minecraft.
Wield **10 different elemental attributes** — Ice, Electric, Corrosion, Holy, Fire, Wind, Water, Thunder, Dark, and Miasma — and pierce through your enemies' defenses!

### ✨ 主な特徴 / Key Features

* 🗡️ **多彩な武器 / Various Weapons** — 直刀・刀・大太刀・魔法武器など、複数の独自武器を追加 / Adds katanas, longswords, magical weapons and more
* 🛡️ **鞘システム / Sheath System** — 抜刀・納刀のアクションで戦闘に没入感を / Draw and sheathe your blade for immersive combat
* 🌈 **10種の属性 / 10 Elements** — それぞれが独自の効果を持つ10種類の属性 / 10 distinct elements, each with unique effects
* 🛡️ **カウンター属性システム / Counter System** — 本スロットの魔導書で属性ダメージを無効化 / Negate elemental damage with the right magic book
* 🎯 **スキルカスタマイズ / Skill Customization** — 武器ごとに攻撃モーションを自由に組み合わせ / Customize attack motions per weapon type
* ⚔️ **カスタム難易度 / Custom Difficulty** — `creative+` から `nightmare`・`lunatic_extreme` まで多彩な難易度 / From `creative+` to `nightmare` and `lunatic_extreme`
* 👥 **戦闘AIを持つ敵Mob / Combat AI Mob** — 回避・チャージ・ガードを使いこなす一般兵 / Common Soldier dodges, charges, and guards
* 🗃️ **武器ラック / Weapon Rack** — お気に入りの武器を飾れる装飾ブロック / A decorative block to display your weapons

***

## 📖 遊び方 / How to Play

### 基本操作 / Basic Controls

| 操作 / Action             | 方法 / Input                                                                                                                                |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 通常攻撃 / Normal Attack    | メインハンドに武器を持って左クリック / Left-click while holding a weapon in your main hand                                                                  |
| チャージ攻撃 / Charged Attack | メインハンドに武器を持って左クリック長押し / Hold left-click while holding a weapon in your main hand                                                          |
| 回避 / Dodge              | オフハンドに鞘を持って右クリック、またはメインハンドに武器を持って右クリック / Right-click while holding a Sheath in your off-hand, or while holding a weapon in your main hand |

### 🎯 スキルセレクション / Skill Selection

専用UIから **1st Hit / 2nd Hit / 3rd Hit / Charged / Dash / Right Click / Shift+Right Click** の各アクションに割り当てるスキル（Thrust・Upper-Left Slash・Spin Slash・Slam Down・Dash Rush・Leap Slash・Shadow Step・Guard など）を自由に組み合わせられます。武器タイプ（Katana / Rapier / Straight Sword / Sword / Greatsword / Dagger / Shield / Bow / Crossbow / Throwing / Trident）ごとに別構成を保存可能です。

Open the **Skill Selection** screen to customize which moves trigger on each action slot (1st/2nd/3rd Hit, Charged, Dash, Right Click, Shift+Right Click). Each weapon category — Katana, Rapier, Straight Sword, Sword, Greatsword, Dagger, Shield, Bow, Crossbow, Throwing, Trident — keeps its own loadout.

![Skill Selection 画面 / Skill Selection screen](https://raw.githubusercontent.com/Drowse-Lab/The-four-primitives-and-Weapons/1.20.1/images/skill_selection.png)

### ✨ Special Technique

**Storm Item** などを **本スロット（magic book スロット）** にセットした状態で、**Magisches Feen Katana** または **Magical Katana** でチャージ攻撃を行うと、Special Technique が発動します！

Set a **Storm Item** (or similar) in the **book slot (magic book slot)**, then perform a **Charged Attack** with a **Magisches Feen Katana** or **Magical Katana** to trigger a powerful **Special Technique**!

![本スロット（magic book）の位置 / The "magic book" slot location](https://raw.githubusercontent.com/Drowse-Lab/The-four-primitives-and-Weapons/1.20.1/images/magic_book_slot.png)

## 🛡️ 鞘システム / Sheath System

各武器には専用の **鞘（Saya）** が存在し、Curios の **Belt / Back スロット** に装備できます。鞘に武器を「納刀」しておくと、ツールチップで現在納刀中の武器が確認できます。

Each weapon has a dedicated **Saya (sheath)** that can be equipped in the Curios **Belt / Back slot**. When a weapon is sheathed, the tooltip shows which weapon is currently stored.

![Straight Sword Saya のツールチップ（Belt/Back スロット・納刀中表示）/ Saya tooltip showing Belt/Back slots and the currently sheathed weapon](https://raw.githubusercontent.com/Drowse-Lab/The-four-primitives-and-Weapons/1.20.1/images/straight_sword_saya_tooltip.png)

![Curios インベントリ画面 / Curios inventory screen](https://raw.githubusercontent.com/Drowse-Lab/The-four-primitives-and-Weapons/1.20.1/images/curios_inventory.png)

## 🌪️ 属性システム / Elemental System

このModには **10種類の属性** が存在します。それぞれ独自の効果を持ち、レベルに応じて強化されます。
This mod features **10 elemental attributes**, each with unique effects that scale with level.

### <span style="color:#c2e0f4">氷 / Ice</span>

凍結中の敵に追加ダメージを与え、Slowness（鈍化）効果を付与します。
Deals bonus damage to frozen enemies and applies Slowness.

* 基礎倍率 / Base multiplier: **1.5×**（+0.25× per level）
* Slowness 継続中は最大 +0.5× の追加ボーナス / Up to +0.5× bonus while Slowness is active

### <span style="color:#f1c40f">電気 / Electric</span>

水中で範囲攻撃（AOE）が発生します。導体装備の敵ほど威力が上がります。
Triggers AOE damage in water. Bonus damage against enemies wearing conductive armor.

* 基礎倍率 / Base multiplier: **1.2×**
* 水中 / In water: **1.5×**
* 導体装備 1個ごとに / Per conductive item: **+0.3×**

### <span style="color:#ff00c8">侵食 / Corrosion</span>

攻撃するたびに敵の防御力を削り取ります。高レベルでは Wither 効果も付与します。
Reduces enemy armor on every hit. Higher levels also apply Wither.

* 基礎倍率 / Base multiplier: **1.1×**
* 防御力減少 / Armor reduction: **−(2.0 + damage × 0.5)**

### <span style="color:#fbeeb8">聖 / Holy</span>

アンデッドに強力な特攻ダメージを与えます。高レベルでは炎上効果も付与します。
Deals massive bonus damage to undead. Higher levels also set enemies on fire.

* 基礎倍率 / Base multiplier: **1.1×**
* アンデッド特攻 / vs. Undead: **2.5×**（+0.3× per level）

### <span style="color:#5d3a8c">闇 / Dark</span>

暗所（光レベル7以下）で大幅な威力ボーナス。Blindness を付与し、高レベルでは独自の持続ダメージ（DoT）も。
Massive damage bonus in dark areas (light level ≤7). Applies Blindness and, at higher levels, custom damage-over-time.

* DoT発動 / DoT activates at: **Lv3+**
* DoTダメージ / DoT damage: **0.5/tick** + **+0.5/Lv**

### <span style="color:#ff6347">火 / Fire</span>

ヒット時に対象を炎上させます。レベルが上がるほど炎上時間が延長されます。
Sets the target on fire on hit. Higher levels extend the burn duration.

* 炎上時間 / Burn duration: **3秒** + **2秒/Lv**

### <span style="color:#88d99c">風 / Wind</span>

攻撃時に **自分（攻撃者）に Strength バフ** を付与します。連続戦闘で火力が伸びる属性。
Grants the attacker a **Strength buff** on hit. Damage scales the longer you fight.

* バフ持続 / Buff duration: **5秒** + **2秒/Lv**
* 攻撃力ボーナス / Attack boost: **+20%** + **+10%/Lv**

### <span style="color:#b388ff">雷 / Thunder</span>

電気属性と同様に水中AOEを発生させます。導体装備にも追加ダメージ。
Like Electric, triggers AOE damage in water. Bonus against conductive armor.

### <span style="color:#4dabf7">水 / Water</span>

敵に強力な Slowness II を付与し、機動力を奪います。
Applies a powerful **Slowness II** to enemies, crippling their mobility.

* Slowness 持続 / Slowness duration: **4秒** + **2秒/Lv**

### <span style="color:#95a85a">瘴気 / Miasma</span>

敵の **回復を阻害** し、持続ダメージ（DoT）を与えます。回復薬や金リンゴが効かなくなる、戦略性の高い属性。
**Blocks enemy healing** and deals damage-over-time. Healing potions and golden apples become ineffective — a highly strategic element.

* 回復阻害持続 / Healing block duration: **5秒** + **3秒/Lv**
* DoT持続 / DoT duration: **3秒** + **2秒/Lv**

Equip a **counter-element magic book** in the **book slot** to negate incoming elemental damage. This adds a deep layer of strategy to combat.

## ⚔️ カスタム難易度 / Custom Difficulty

バニラの easy / normal / hard に加え、独自難易度を多数追加。コマンドで切り替え可能です。
In addition to vanilla easy / normal / hard, this mod adds custom difficulties switchable via command.

| 難易度 / Difficulty | 概要 / Overview                                       |
| ---------------- | --------------------------------------------------- |
| `creative+`      | クリエイティブ以上の自由度 / Even more permissive than creative   |
| `peaceful`       | 平和 / Peaceful                                       |
| `easy`           | バニラ準拠 / Vanilla                                    |
| `normal`         | バニラ準拠 / Vanilla                                    |
| `hard`           | バニラ準拠 / Vanilla                                    |
| `realistic`      | リアル志向 / Realistic combat tuning                     |
| `lunatic`        | 高難易度 / High difficulty                              |
| `lunatic+`       | 超高難易度 / Even harder                                |
| `lunatic_extreme`| 極端な高難易度 / Extreme                                  |
| `nightmare`      | 悪夢 / Nightmare-tier                                 |

切り替えコマンド / Switch with:

```
/gamerule difficulty <難易度名>
```

## 👤 一般兵 / Common Soldier

プレイヤーのような戦闘AIを持つ敵Mobです。回避・チャージ攻撃・ガードスキルを使います。
A hostile mob with player-like combat AI — it dodges, charges, and guards just like a real player.

| ステータス / Stat        | 値 / Value                  |
| ------------------- | -------------------------- |
| HP                  | 40                         |
| 攻撃力 / Attack        | 5                          |
| 防御力 / Armor         | 4（鉄装備相当 / Iron equivalent） |
| 回避成功率 / Dodge rate  | 30%                        |
| チャージ率 / Charge rate | 50〜80%                     |

召喚コマンド / Summon command:

```
/summon minecraft_armor_weapon:common_soldier ~ ~ ~
```

## 🧪 ステータス効果の活用 / Using Status Effects

Mobにステータス効果を付与することでAIを弱体化できます（プレイヤーには影響しません）。
Applying status effects to mobs weakens their AI. These effects do not affect players.

| 効果 / Effect    | 主な影響 / Main Impact                                                       |
| -------------- | ------------------------------------------------------------------------- |
| 盲目 / Blindness | 視界−70%・移動速度−30%・回避が70%失敗 / Vision −70%, Speed −30%, Dodge fails 70%      |
| 吐き気 / Nausea   | 回避方向ランダム化・チャージ方向が±45°ズレ / Random dodge direction, Charge aim offset ±45° |
| 弱体化 / Weakness | 攻撃力−4（バニラ効果に追加）/ Attack −4 (on top of vanilla)                           |
| 暗闇 / Darkness  | 視界−50%・チャージ範囲−50% / Vision −50%, Charge range −50%                       |

複数効果の重複が可能です。盲目＋混乱＋弱体化を同時付与するとAIがほぼ機能しなくなります。
Effects stack. Combining Blindness + Nausea + Weakness nearly disables the AI entirely.

```
/effect give @e[type=!minecraft:player,distance=..10] minecraft:blindness 30 0
```
