# 拵え（柄・鍔・縁・頭）テクスチャの描き方

刀の各部位を着せ替えるテクスチャの**描き方**。色は実行時に染料で乗るので、テクスチャは**グレースケール**で描く。
編集用の**テンプレ画像**を `template_*.png` として同梱（コピーして描き始める用）。

---

## 大原則（全部位共通）

1. **グレースケールで描く**（R=G=B）。色は染料で乗算される。
   - 明るい所＝選んだ色が鮮やかに出る／暗い所＝影／**真っ黒(0)は不可**（色が乗らない）。
   - 目安：紐/金属の地 = 120〜170、ハイライト = 200〜240、影 = 80〜110。
2. **透明 = 元の刀が透ける**。透かし鍔や、地を見せたい所は透明に。
3. **1枚が面に丸ごと貼られる**（per-face full）。UVの一部に描くのではなく、**1タイルで完結する模様**にする。
   - 細かすぎるとつぶれる。モチーフは**少なめ・大きめ**に。

---

## 部位ごとの描き方

### 柄巻き（つか） `tsuka/<id>.png` … 32×48（縦長）
紐に見せるのが命。**平らな帯はNG**。
- **丸い縒り紐**にする：紐の幅方向に「端=暗 → 中央=明 → 端=暗」のグラデ（かまぼこ断面）。
- 紐を**斜め2方向**（／と＼）で交差させて**菱**を作る。菱は **2〜4個/面** の大きさ。
- 菱の開口に**鮫皮**を覗かせる：明るい灰(210前後)＋**白い細かい粒**をパラパラ。
- `template_tsuka.png` に菱のガイド線入り。線の上を紐、間を鮫皮で塗る。
- 巻きを増やす→ id を `KatanaFittings.WRAPS` に追加（コード）。

```
／＼／＼   ← 紐(かまぼこ陰影)が交差
 ◇ ◇    ← 開口に鮫皮(明+粒)
＼／＼／
```

### 鍔（つば） `tsuba/<id>.png` … 16×16
- tint2 面に丸貼り＋色が乗る。金属の地(140〜170)＋彫り/筋を影で。
- **透かし鍔**は穴を透明に（地＝刀が見える）。
- id を `KatanaFittings.TSUBAS` に追加（コード）。

### 縁・頭（ふち／かしら）
- 現状は**色のみ**（テクスチャ差し替え無し）。金具の地 × 染料色で着色。
- 別テクスチャにしたい場合は鍔と同じ差し替えを足す改修が要る（要望で対応）。

---

## サイズ・置き場
| 部位 | サイズ | パス |
|---|---|---|
| 柄巻き | 32×48 | `textures/katana_fitting/tsuka/<id>.png` |
| 鍔 | 16×16 | `textures/katana_fitting/tsuba/<id>.png` |

- 置くだけでアトラスに stitch される（`assets/minecraft/atlases/blocks.json` の `katana_fitting` ソース）。
- **テクスチャは全武器で共有**（刀/直刀/剣/レイピア）。武器ごとに別デザインにしたい場合のみコード改修。
- 反映は **F3+T**（モデル/レシピを変えた時はゲーム入り直し）。

---

## テンプレの使い方
1. `template_tsuka.png`（菱ガイド付き）/ `template_tsuba.png` をコピー。
2. ガイドに沿ってグレースケールで描く（紐＝かまぼこ陰影、開口＝明るい鮫皮）。
3. `tsuka/<好きなid>.png` 等にリネームして保存。
4. id をコード（`KatanaFittings.WRAPS` / `TSUBAS`）に追加。

> 色は描かない（染料で付く）。明るさだけで立体感を作るのがコツ。
