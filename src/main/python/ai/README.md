# ALife AI System - プレイヤーっぽい動きをするMobシステム

## 概要

このシステムは、ALife（人工生命）の概念を使用して、プレイヤーのような知的な動きをするMobを実現します。

## 主要機能

### プレイヤースタイル戦闘システム

#### 攻撃タイプ
1. **通常攻撃**: 基本的な近接攻撃
   - 武器タイプ別のコンボ（直刀：突き、刀：斬撃）
   - ティア毎に異なるコンボ数

2. **ダッシュ攻撃**: 高速移動 + 攻撃
   - 範囲: 7～13ブロック（ティア依存）
   - ダメージ倍率: 1.5～2.8倍

3. **チャージ攻撃**: 溜め攻撃
   - 範囲: 5～8ブロック（ティア依存）
   - ダメージ倍率: 2.0～4.0倍（チャージレベル依存）
   - プレイヤー相手により積極的

#### 属性攻撃（ティア2以上）
- **火属性**: 炎上ダメージ
- **氷属性**: 移動速度低下
- **雷属性**: スタン効果（ティア4以上）

#### 戦術システム
- **撤退判断**: HP、敵の数、敵の強さを判断
- **回復**: 安全な場所で自動回復
- **位置取り**: 最適な戦闘位置を選択
- **カウンター**: 攻撃のタイミングを読んで反撃（ティア3以上）
- **パリィ**: 攻撃を弾く（ティア4以上）

### 状態機械（State Machine）
- **IDLE**: 待機
- **PATROL**: 巡回
- **SEARCH**: 探索
- **COMBAT**: 戦闘
- **RETREAT**: 撤退
- **DODGE**: 回避
- **HEAL**: 回復
- **REPOSITION**: 位置調整

### 学習と適応
- ダメージを受けた状況を記憶
- 回避成功/失敗から学習
- 敵の行動パターンを分析
- ティアに応じた学習速度

## テスト方法

### 各ティアのテスト

```python
# ティア1
from CommonSoldier import create_ai
ai = create_ai(entity_data)

# ティア2
from EliteSoldier import create_ai
ai = create_ai(entity_data)

# ティア3
from singularity import create_ai
ai = create_ai(entity_data)

# ティア4
from HeroicTier import create_ai
ai = create_ai(entity_data)

# テストデータ
entity_data = {
    "health": 20.0,
    "max_health": 20.0,
    "position": (0, 0, 0)
}

world_data = {
    "nearest_enemy_position": (5, 0, 0),
    "nearest_enemy_distance": 5.0,
    "current_time": 0,
    "incoming_attack": False,
    "nearby_enemies": []
}

# 更新ループ
for i in range(100):
    action = ai.update(0.05, world_data)  # 50ms毎
    print(f"State: {ai.current_state.value}, Action: {action['action']}")
```

## 技術詳細

### AIアーキテクチャ

```
BaseALifeAI (基本クラス)
    ├── 状態機械
    ├── 意思決定システム
    ├── 学習システム
    └── 行動選択
         │
         └── PlayerStyleBaseAI (プレイヤースタイル基底)
              ├── 武器システム
              ├── 攻撃パターン
              ├── 回避システム
              └── 戦術判断
                   │
                   ├── CommonSoldierAI (ティア1) ✅
                   ├── EliteSoldierAI (ティア2) ✅
                   ├── SingularityAI (ティア3) ✅
                   └── HeroicTierAI (ティア4) ✅
```

### パラメータ調整

各ティアのパラメータは各クラスのコンストラクタで調整できます：
- `attack_range`: 攻撃範囲
- `dash_attack_range`: ダッシュ攻撃範囲
- `charge_attack_range`: チャージ攻撃範囲
- `dodge_success_rate`: 回避成功率
- `combo_max`: 最大コンボ数
- `elemental_types`: 使用可能な属性
- `elemental_attack_chance`: 属性攻撃確率

## 注意事項

1. **パフォーマンス**: 高ティアのAIは計算量が多いため、同時に多数スポーンすると重くなる可能性があります
2. **バランス調整**: 各ティアの強さは継続的に調整が必要です
3. **Python実行環境**: 現在はJavaで直接実装していますが、将来的にはJythonやGraalVMを使用してPythonコードを実行予定です
