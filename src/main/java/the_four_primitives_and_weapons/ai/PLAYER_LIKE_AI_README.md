# プレイヤーのような動きをするAIシステム

このシステムは、エンティティ（Mob）がプレイヤーと同じような動作をできるようにするためのAIシステムです。

## 概要

プレイヤーの動作をAIが模倣できるように実装されています：

### プレイヤーの動作
- **回避（右クリック）**: プレイヤーが右クリックで回避する動作
- **チャージ攻撃（左クリック長押し）**: 左クリックを長押ししてチャージし、離すと強力な攻撃
- **武器スキル（右クリック）**: ReplicaSwordOfLightのガードスキルなど

### AIの動作
AIは同じ動作を自動的に判断して実行します：
- **回避**: 敵が近すぎる場合や攻撃が来る場合に自動で回避
- **チャージ攻撃**: 適切な距離（3～7ブロック）で自動的にチャージ攻撃
- **武器スキル**: 敵が近い場合（5ブロック以内）に防御スキルを使用

## 使い方

### 1. エンティティにAIを追加

Mobエンティティのコンストラクタまたは初期化時に、`PlayerLikeAIGoal`を追加します：

```java
import the_four_primitives_and_weapons.ai.PlayerLikeAIGoal;

public class YourMobEntity extends Monster {

    @Override
    protected void registerGoals() {
        super.registerGoals();

        // プレイヤーのような動作をするAIを追加
        // 第2引数はティア（1～7）
        // ティアが高いほど、回避率が高く、チャージ時間が長い
        this.goalSelector.addGoal(1, new PlayerLikeAIGoal(this, 1));

        // 他のGoalも追加可能
        this.goalSelector.addGoal(2, new MeleeAttackGoal(this, 1.0, false));
        this.targetSelector.addGoal(1, new NearestAttackableTargetGoal<>(this, Player.class, true));
    }
}
```

### 2. ティアシステム

AIのティアによって動作が変わります：

| ティア | 名称 | 回避率 | 戦術認識度 | チャージ率 |
|--------|------|--------|------------|------------|
| 1 | 一般兵 | 30% | 30% | 50-80% |
| 2 | エリート兵 | 50% | 50% | 50-100% |
| 3 | 特異点 | 70% | 70% | 60-100% |
| 4 | 英雄級 | 80% | 80% | 65-100% |
| 5 | 神話級 | 90% | 90% | 70-100% |
| 6 | 天使級 | 95% | 95% | 72.5-100% |
| 7 | 神聖級 | 99% | 100% | 75-100% |

### 3. カスタマイズ

Python AIファイル（`src/main/python/ai/`）を編集することで、AIの動作をカスタマイズできます：

- `base_alife_ai.py`: 基本AIクラス
- `CommonSoldier.py`: 一般兵（ティア1）
- `EliteSoldier.py`: エリート兵（ティア2）
- その他のティア用AIファイル

各AIクラスで以下のメソッドをオーバーライドできます：

```python

    """武器スキルを使用すべきかを判定"""
```

## 実装の詳細

### アーキテクチャ

```
Python AI (判断)
    ↓
Java AIBridge (橋渡し)
    ↓
PlayerLikeAIGoal (実行)
    ↓
Minecraft Entity (動作)
```

1. **Python AI** (`base_alife_ai.py`):
   - 戦術的な判断を行う
   - プレイヤーと同じ動作をすべきかを決定
   - アクションデータを返す

2. **Java AIBridge** (`ALifeAIBridge.java`):
   - Python AIとMinecraftの橋渡し
   - ワールドデータを収集
   - Python AIからのアクションをJavaに変換

3. **PlayerLikeAIGoal** (`PlayerLikeAIGoal.java`):
   - Minecraft AIGoalとして実装
   - 実際のエンティティの動作を制御
   - プレイヤーの動作を模倣

### 動作の仕組み

#### 回避（Dodge）
```
1. 敵が近い（2ブロック以内）を検知
2. ティアに応じた確率で回避を決定
3. 敵から離れる方向に移動
4. 上方向に少し浮く（0.15ブロック）
5. 煙エフェクトとサウンド
6. 1.5秒間落下ダメージ無効
7. 2秒間のクールダウン
```

#### チャージ攻撃（Charge Attack）
```
1. 敵が適切な距離（3～7ブロック）を検知
2. ティアに応じてチャージ率を決定
3. チャージ中のエフェクト（ELECTRIC_SPARK）
4. 直線上の全ての敵にダメージ
5. チャージ率に応じたダメージ倍率
6. 敵を吹き飛ばす
7. サウンドエフェクト
8. 2秒間のクールダウン
```

#### 武器スキル（Weapon Skill）
```
1. 敵が近い（5ブロック以内）を検知
2. ティアに応じた確率でスキル使用を決定
3. GUARDエフェクトを付与（5秒間）
4. LONG_RANGE_WEAPON_CUTエフェクトを付与
5. エンチャントエフェクトとサウンド
6. 3秒間のクールダウン
```

## プレイヤーとの対応表

| プレイヤーの動作 | 対応するAI動作 | トリガー条件 |
|-----------------|---------------|-------------|
| 右クリック（回避） | `executeDodge()` | 敵が2ブロック以内 |
| 左クリック長押し（チャージ） | `executeChargeAttack()` | 敵が3～7ブロック |
| 右クリック（スキル） | `executeWeaponSkill()` | 敵が5ブロック以内 |
| 左クリック（通常攻撃） | `executeNormalAttack()` | 敵が3ブロック以内 |

## 注意事項

- Python AIファイルは現在はJavaで直接実装されています（将来的にPython連携予定）
- エンティティに武器を持たせる必要はありませんが、持たせるとより良いエフェクトが表示されます
- ティアが高すぎると、AIが強すぎてプレイヤーが倒せなくなる可能性があります
- 複数のPlayerLikeAIGoalを同じエンティティに追加しないでください

## トラブルシューティング

### AIが回避しない
- ティアが低すぎる（ティア1は30%の確率）
- クールダウン中（2秒間は回避できない）
- 敵が遠すぎる（2ブロック以内で回避判定）

### AIがチャージ攻撃しない
- 敵との距離が適切でない（3～7ブロックが最適）
- クールダウン中（2秒間はチャージできない）
- ティアが低すぎる

### AIがスキルを使わない
- 敵が遠すぎる（5ブロック以内で使用）
- クールダウン中（3秒間は使用できない）
- ティアが低すぎる
