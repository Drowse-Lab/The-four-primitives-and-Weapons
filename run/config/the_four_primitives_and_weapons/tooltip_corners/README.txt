このフォルダーは Git の追跡対象です。

Minecraft を1度起動すると、次の32x32 PNGが自動生成されます。
common.png
uncommon.png
rare.png
epic.png
legendary.png
forbidden.png

各PNGの配置:
- 左上 16x16: ツールチップの左上角
- 右上 16x16: ツールチップの右上角
- 左下 16x16: ツールチップの左下角
- 右下 16x16: ツールチップの右下角

四辺の直線も同じPNGから描画されます。
- 上辺: (15, 1) のピクセル
- 下辺: (15, 30) のピクセル
- 左辺: (1, 15) のピクセル
- 右辺: (30, 15) のピクセル

この4ピクセルの色と透明度が、それぞれ角の間まで引き伸ばされます。
角側の線を同じ位置・色にすると、継ぎ目なくつながります。

ペイントアプリで編集しても32x32のまま保存してください。
透明ピクセルは描画されません。保存後はゲーム中で自動再読み込みされます。
