このフォルダーは Git の追跡対象です。

Minecraft を1度起動すると、次の32x32 PNGが自動生成されます。
common.png
uncommon.png
rare.png
epic.png
legendary.png
forbidden.png

各PNGの配置:
- 左上 16x16: ツールチップの左上角
- 右上 16x16: ツールチップの右上角
- 左下 16x16: ツールチップの左下角
- 右下 16x16: ツールチップの右下角

ペイントアプリで編集しても32x32のまま保存してください。
透明ピクセルは描画されません。保存後はゲーム中で自動再読み込みされます。
